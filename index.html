Research & Projects

Cube Grasping with π0

Robot Learning / MuJoCo / Physical Robot

Used the open-source π0 model for cube grasping. Collected teleoperation data, trained the model, ran inference in MuJoCo, and tested it on a physical robot.

Prompt-Based Few-Shot Reinforcement Learning

Reinforcement Learning / Retrieval / In-context Learning

Combined prompt planning with a retrieval agent to select task-relevant few-shot examples during sampling, aiming to help the policy explore more efficiently.

RAG-Based Question Answering System

Large Language Models / Sentence-Transformer / Vector Database

Built a question-answering system for product manuals. Split the manuals into passages, stored their embeddings in a vector database, and used retrieved passages as context for the model's answers.

Neural Network Architectures on Iris

Machine Learning / Regularization / Feature Engineering

Compared neural network architectures, initialization methods, loss functions, dropout, and label smoothing on the Iris dataset. Also tested sepal area as an additional feature.
