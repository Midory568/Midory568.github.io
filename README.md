# Personal Homepage

This repository contains the personal homepage of Shengting Liu, an undergraduate student majoring in Automation at the University of Science and Technology of China (USTC). The site presents academic interests, selected projects, and personal notes in a lightweight static website.

## Focus Areas

- Embodied AI and physical robot workflows
- Reinforcement learning and few-shot learning
- LLM applications, retrieval, and RAG systems
- Robotic data collection and simulation with MuJoCo

## Website Content

- **Profile** — an introduction, academic background, skills, news, and selected research projects.
- **Anime** — personal anime notes, a feature on Soryu Asuka Langley, and an introduction to *Neon Genesis Evangelion*.
- **Visit** — city notes for Hong Kong, Tokyo, Osaka, and Sapporo.

## Project Structure

- `index.html` — the main profile page
- `pages/` — Anime, Visit, city, and character detail pages
- `images/` — profile, anime, and travel images
- `styles.css` — shared responsive styles for all pages

The website is designed as a static GitHub Pages site and can be viewed through the repository's published homepage.
